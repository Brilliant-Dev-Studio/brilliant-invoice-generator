# Noto Sans Myanmar

Self-hosted Unicode Myanmar faces, weights 400, 500, 600, and 700.
Source: locally available NotoSansMyanmar.ttc, version 22.0d3e1.
Each face declares SIL OFL 1.1 licensing and unrestricted embedding.
Converted to WOFF with FontTools 4.62.1; glyphs and shaping tables retained.
Only Unicode Myanmar faces are included, not the Zawgyi faces.
