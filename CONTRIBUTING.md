# Contributing

Thank you for helping improve San Pya / Brilliant Invoice Generator.

## Pull requests (recommended)

GitHub counts **merged pull requests** toward profile achievements such as **Pull Shark**. Direct pushes to `main` do not.

1. Fork or create a branch: `git checkout -b your-topic`
2. Make focused changes; run `npm run lint`, `npm run typecheck`, and `npm test`
3. Push and open a pull request against `main`
4. Merge when CI is green

See [docs/github-achievements.md](docs/github-achievements.md) for a full guide to earning GitHub profile badges legitimately on this project.

## Co-authored commits

To progress **Pair Extraordinaire**, a real collaborator can co-author a commit on a merged PR:

```text
Co-authored-by: Name <email@example.com>
```

Add that line to the commit message (both authors should use GitHub-linked emails).

## Reporting issues

Use **Issues** with the bug or feature template. For questions, enable **Discussions** on the repository (Settings → General) and use the Q&A category for **Galaxy Brain**-style accepted answers.

## Code style

Match existing patterns in the file you edit. Run `npm run format` before committing when you touch many files.
